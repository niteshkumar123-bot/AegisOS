# Learner Profile

## Initial Idea

> AegisOS is a developer tool that helps verify coding tasks instead of blindly trusting AI-generated results. The goal for the hackathon is a focused proof of concept: a user submits a coding task, the system runs relevant checks and tests in a controlled environment, and the dashboard shows whether the task passed or failed with test evidence.
